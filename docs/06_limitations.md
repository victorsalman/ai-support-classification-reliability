# Limitations

This case study is intentionally explicit about what the evidence does not establish.

1. All customer messages were synthetic.
2. The test set was small.
3. The controlled model outputs were produced inside a GPT 5.6 Sol conversation.
4. The runs were not independent API executions.
5. No real customer traffic was used.
6. No production application was deployed.
7. No latency measurements were recorded.
8. No token cost or operating cost measurements were recorded.
9. No throughput measurements were recorded.
10. No independent security validation was performed.
11. No claim of production accuracy is made.
12. No professional software engineering implementation is claimed.

The case study demonstrates prompt engineering methodology, architecture reasoning, failure analysis, uncertainty preservation, and controlled regression testing.
